🚀 WebServ - HTTP Server em C++ 98

Guia Completo do Projeto | Escola 42

📋 Visão Geral do Projeto

Desenvolver um servidor HTTP completo em C++ 98, não-bloqueante, capaz de servir websites estáticos, processar CGI e gerenciar múltiplas conexões simultaneamente.

O projeto "webserv" da Escola 42 é uma implementação de um servidor HTTP em C++98, inspirado no protocolo HTTP (principalmente versão 1.0 ou 1.1, com base no RFC). O objetivo é criar um servidor web que lide com requisições de clientes (como navegadores ou ferramentas como telnet), processe configurações via arquivo, gerencie I/O não bloqueante e suporte funcionalidades básicas como servir arquivos estáticos, uploads, métodos HTTP (GET, POST, DELETE) e execução de CGIs (como PHP ou Python). É um projeto desafiador que testa conceitos de redes, programação assíncrona e gerenciamento de recursos em sistemas Unix-like.

⚠️ Armadilhas Comuns

🚫 NÃO FAZER:
  • ❌ Usar read/write sem poll() → Nota 0
  • ❌ Bloquear o servidor em qualquer operação
  • ❌ Usar execve para lançar outro servidor
  • ❌ Verificar errno após read/write
  • ❌ Fork para coisas além de CGI
  • ❌ Memory leaks ou file descriptor leaks
✅ FAZER:
  • ✓ Testar com telnet e curl
  • ✓ Comparar comportamento com NGINX
  • ✓ Stress test (múltiplas conexões simultâneas)
  • ✓ Usar valgrind para detectar leaks
  • ✓ Testar com browsers reais
  • ✓ Implementar timeouts para conexões

📚 Recursos Importantes

RFCs para Estudar:

  • RFC 2616 - HTTP/1.1 (especialmente seções 4, 5, 6, 9)
  • RFC 1945 - HTTP/1.0 (mais simples para começar)
  • RFC 3875 - CGI Specification

Conceitos Chave:

  • Non-blocking I/O - fcntl(fd, F_SETFL, O_NONBLOCK)
  • poll() - Multiplexing de I/O
  • HTTP Request - Method, Path, Headers, Body
  • HTTP Response - Status Line, Headers, Body
  • CGI - Environment variables, stdin/stdout
  • Chunked Transfer - Transfer-Encoding: chunked

Ferramentas de Teste:

  • telnet localhost 8080 - Teste manual
  • curl -v http://localhost:8080 - Debug HTTP
  • siege -c 100 -r 10 URL - Stress test
  • valgrind --leak-check=full ./webserv - Memory leaks
  • Postman/Insomnia - Testar POST/DELETE

🎁 Bonus (se tudo obrigatório funcionar)

  • 🍪 Cookies e gestão de sessões
  • 🔧 Múltiplos tipos de CGI
Atenção: Bonus só conta se a parte obrigatória estiver 100% funcional!

✨ Exemplo de Configuração

server {
    listen 8080;
    server_name localhost;
    
    error_page 404 /errors/404.html;
    client_max_body_size 10M;
    
    location / {
        root /var/www/html;
        index index.html;
        allowed_methods GET POST;
    }
    
    location /upload {
        root /var/www/uploads;
        allowed_methods POST DELETE;
        client_body_temp_path /tmp;
    }
    
    location /cgi-bin {
        root /var/www/cgi;
        cgi_extension .php;
        cgi_path /usr/bin/php-cgi;
    }
}
